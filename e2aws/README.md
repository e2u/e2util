# e2aws

## Overview
The `e2aws` module provides utilities for interacting with AWS services, including S3, DynamoDB, and IAM helpers.

## Installation
```bash
go get github.com/e2u/e2util/e2aws
```

## Usage
```go
import "github.com/e2u/e2util/e2aws"

// Example: create an S3 client
client := e2aws.NewS3Client(cfg)
```
