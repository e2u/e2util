# e2model

## Overview
`e2model` defines shared data structures and model helpers used across the e2util ecosystem.

## Installation
```bash
go get github.com/e2u/e2util/e2model
```

## Usage
```go
import "github.com/e2u/e2util/e2model"

type User = e2model.User
```
