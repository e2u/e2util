# e2math

## Overview
`e2math` offers mathematical helper functions, such as rounding, clamping, and statistical calculations.

## Installation
```bash
go get github.com/e2u/e2util/e2math
```

## Usage
```go
import "github.com/e2u/e2util/e2math"

rounded := e2math.Round(3.14159, 2)
```
