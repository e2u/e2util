# e2auth

## Overview
The `e2auth` module provides authentication and authorization utilities, including user management, session handling, password reset, email verification, MFA, OAuth, CAPTCHA, and admin functionality.

## Installation
```bash
go get github.com/e2u/e2util/e2auth
```

## Usage
```go
import "github.com/e2u/e2util/e2auth"

// Example: initialize router with configuration
cfg := e2auth.NewConfig(...)
router := e2auth.NewRouter(cfg)
```
