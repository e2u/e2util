# e2unit

## Overview
`e2unit` provides utilities for unit testing, including custom assertions, test suites, and mocking helpers.

## Installation
```bash
go get github.com/e2u/e2util/e2unit
```

## Usage
```go
import "github.com/e2u/e2util/e2unit"

func TestSomething(t *testing.T) {
    e2unit.AssertEqual(t, 1, 1)
}
```
